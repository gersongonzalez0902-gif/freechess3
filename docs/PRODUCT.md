# Producto FreeChess

**Eslogan:** Todo el ajedrez. Una sola plataforma. Gratis para todos.

FreeChess es una plataforma gratuita para jugar localmente, entrenar, aprender y analizar ajedrez. Las funciones principales no se bloquearán detrás de suscripciones.

## Modos de juego

- Partidas entre dos personas en el mismo dispositivo.
- Partidas contra bots cuando el motor esté integrado y verificado.

No habrá partidas online entre usuarios.

## Principios de experiencia

- Interfaz propia, sobria y centrada en el tablero.
- Verde profundo, superficies oscuras y acento menta; modo claro disponible.
- Responsive y accesible por teclado.
- No mostrar estadísticas inventadas.
- Distinguir claramente entre funciones disponibles y funciones en desarrollo.
